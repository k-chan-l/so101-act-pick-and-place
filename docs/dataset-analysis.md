## 2. 다중 시도 시연이 존재하는가 (Round 5)

그리퍼 개폐를 히스테리시스(열림 >20, 닫힘 <8)로 상태 추적해 에피소드별 파지 시도 횟수를 셌습니다.

```python
OPEN, CLOSED = 20.0, 8.0
for e, d in df.groupby('episode_index'):
    g = d['g'].values
    st = 'open' if g[0] > OPEN else 'closed'   # 홈에서 그리퍼가 닫힌 채 시작함에 주의
    closes = []
    for k, v in enumerate(g):
        if st == 'open' and v < CLOSED:  st = 'closed'; closes.append(k)
        elif st == 'closed' and v > OPEN: st = 'open'
```

**결과**

| | |
| --- | --- |
| 파지가 있는 에피소드 | **42** (그리퍼 닫힘 정확히 1회) |
| 파지가 없는 에피소드 | **8** (ep 42–49 = 엣지 케이스) |
| 닫힘 2회 이상인 에피소드 | **0 / 42 (0%)** |

**학습 데이터에 다중 시도 시연이 하나도 없습니다.** "멈칫한 에피소드는 즉시 삭제" 프로토콜이 지켜졌습니다.

→ Round 5의 재시도 행동은 **시연을 모방한 것이 아닙니다.** → [5차 추론 ⑤](rounds/round5.md)

## 3. 7개 큐브 지점이 데이터에서 구분되는가 (Round 5)

각 에피소드의 **첫 파지 순간** 관절값을 지점별로 묶었습니다. 촬영은 지점당 6회 연속이므로 `episode_index // 6`이 지점 번호이며, **평가 지점 번호 1~7과 순서가 같음을 운영자가 확인**했습니다.

### 지점별 파지 자세

| 지점 | n | j1 (베이스 회전) | j3 (팔 뻗음) | 평가 성공 |
| ---: | ---: | ---: | ---: | ---: |
| 1 | 6 | 78.3 ± 3.8 | 31.6 ± 13.2 | 0/3 |
| 2 | 6 | 77.1 ± 4.0 | 32.1 ± 11.9 | 2/3 |
| 3 | 6 | 72.4 ± 3.4 | 21.5 ± 9.1 | 2/3 |
| 4 | 6 | 72.9 ± 0.9 | 18.3 ± 11.3 | 2/3 |
| 5 | 6 | 68.8 ± 4.1 | 18.8 ± 11.2 | 0/3 |
| 6 | 6 | 70.6 ± 2.8 | 10.5 ± 7.9 | 0/3 |
| 7 | 6 | 65.5 ± 4.1 | 1.1 ± 12.6 | 1/3 |

### 분리도

| 관절 | 7지점 전체 폭 | 지점 간 표준편차 | 지점 내 산포 | **분리비** |
| --- | ---: | ---: | ---: | ---: |
| j1 | 12.8° | 4.5° | 3.3° | **1.36** |
| j3 | 31.0° | 11.0° | 11.0° | **1.00** |

분리비 = 지점 간 표준편차 / 지점 내 산포. **1 근처면 인접 지점의 시연 분포가 서로 겹칩니다.**

- 7개 지점 전체가 베이스 회전 **12.8° 안에** 몰려 있는데 지점 하나의 산포가 ±3.3°입니다.
- 지점 3(72.4±3.4°)과 지점 4(72.9±0.9°)는 베이스 회전각이 **사실상 같습니다.**
- j3은 분리비가 정확히 1.00으로, 지점 간 간격과 지점 내 산포가 같습니다.

**정책이 위치를 암기한 것이 아니라, 애초에 구분할 수 없는 데이터였습니다.** → [5차 검증 ②](rounds/round5.md)

### 중심으로의 mode collapse 가설은 지지되지 않습니다

베이스 회전각 중심(72.2°)에서의 거리와 성공 횟수의 상관은 **−0.35**로 약하고, 가장 바깥 두 지점(1과 7)의 성적이 0/3과 1/3으로 엇갈립니다.

## 4. 지점당 3회로 위치 편차를 판별할 수 있는가 (Round 5)

전 지점 성공률이 동일하게 33%라고 가정한 이항분포 기대값입니다.

| | 기대 | 관측 |
| --- | ---: | ---: |
| 0/3 인 지점 수 | 2.1개 | 3개 |
| 1/3 인 지점 수 | 3.1개 | 1개 |
| 2/3 인 지점 수 | 1.6개 | 3개 |
| 3/3 인 지점 수 | 0.3개 | 0개 |

몬테카를로 20만 회 결과, **관측된 분산(0.86) 이상이 우연히 나올 확률은 16.9%** 입니다.

**"지점 1·5·6이 특별히 나쁘다"는 이 데이터로 주장할 수 없습니다.** 지점당 9회 이상이 필요합니다 (실제 성공률 33%인 지점이 9회 전패할 확률 4.0%).

> 다만 운영자가 육안으로 관찰한 **"엉뚱한 위치로 이동한다"는 행동 자체**는 성공률 통계와 별개의 직접 증거입니다. 통계가 부정하는 것은 "지점별 난이도 차이"이지 "위치 판별 실패"가 아닙니다.
