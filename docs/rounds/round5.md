# 5차 — 통제 재시작 (최종)

| | |
| --- | --- |
| 단계 | 통제 |
| 검증하려는 가설 | 촬영 조건을 통제하고 from scratch로 재수집하면 개선된다 |
| **판정** | **확인** |

**장비 반납으로 이 라운드가 프로젝트의 마지막 실험입니다.**

---

## 설계

1~4차의 결론을 전부 반영해 **데이터를 새로 수집하고 처음부터 학습**했습니다. 이전 라운드의 데이터·가중치를 이어받지 않았습니다.

### 데이터 구성

- 데이터셋: `k-chan-l/pick_and_place5` — **50 에피소드 / 24,407 프레임**

| 종류 | 에피소드 | 구성 |
| --- | --- | --- |
| 정상 시연 | 42 | 7지점 × 6회 (각도 0°/45° 3:3) |
| 엣지 케이스 | 8 | 큐브가 이미 컵 안 4 + 큐브 없음 4 |

- DAgger 교정 17ep는 **제외**했습니다 (4b 결론 2).

### 촬영 조건

전체 조건은 [protocol.md](../protocol.md)의 "5차 통제 실험 조건"에 있습니다. 핵심만:

| 항목 | 값 | 근거 |
| --- | --- | --- |
| 컵 | **물리적으로 고정** | 3차에서 컵 전도 3회로 시행 조건이 흔들림 |
| 큐브 지점 | 7지점, 탈착식 종이 템플릿으로 배치 후 **템플릿 제거** | 표시가 화면에 남으면 큐브 대신 그 표시를 보고 움직이도록 학습 (1차와 같은 실패) |
| 큐브 각도 | 0° / 45° | 3차 가설 1 — 각도 다양성 부족 |
| 위치 오차 | 시연 시 ±1~2cm 랜덤 / 평가 시 정확히 | 학습엔 다양성, 평가엔 재현성 |
| 카메라 | MJPEG, **자동 노출·화이트밸런스 off** | 프레임 간 밝기·색 흔들림 제거 |
| 시연 | **정렬 구간 1~2초 천천히**, 파지 후 멈춤 없이 곧장 컵 | 4b 결론 3 — 중앙 정렬 미학습 |
| 편집 | 멈칫한 에피소드는 즉시 삭제 | 4차 회귀 원인 차단 |

### 학습

- 정책: `k-chan-l/pick_and_place5_act`
- **from scratch** / 100,000 steps / batch_size 16 / seed 1000 / `image_transforms.enable=true`

## 결과

**21회 중 7회 성공 (33%)** — `n_action_steps=100` 기준. **전 라운드 최고 성적입니다.**

| 항목 | 값 |
| --- | --- |
| 총 시행 | 21 (7지점 × 3회) |
| 성공 | **7 (33%)** |
| 근접 오차 | 미분류 |
| 파지 실패 | 14 |
| 파지 후 실패 | **0** |
| 무반응 | 0 |

> 실패 14건은 전부 파지 단계입니다. 운영자 관찰상 "다른 위치를 짚음"(접근 오류)과 "근처에서 파지 실패"가 섞여 있으나 시행 단위로 분리 기록되지 않아 **근접 오차와 파지 실패를 나누지 않았습니다.**

### 지점별 결과

| 지점 | 결과 | 관찰된 행동 |
| --- | --- | --- |
| 1 | 0/3 | 큐브 존재는 인지하는 듯하나 다른 위치를 탐색 |
| 2 | **2/3** | 위치를 어렴풋이 찾음. 주변을 여러 번 헛짚다가 겨우 파지 |
| 3 | **2/3** | 위치를 알고 접근. 주변을 짚다가 파지 성공 |
| 4 | **2/3** | 파지 실패 시 다른 위치로 이동해 재시도 후 파지 |
| 5 | 0/3 | 위치를 모르고 다른 곳을 짚음 |
| 6 | 0/3 | 위치를 모르고 다른 곳을 짚음 |
| 7 | 1/3 | 주변을 짚다 실패하면 다른 곳을 잡으려 함 |

### 운영자 관찰

1. 정책이 큐브를 시각적으로 탐지하지 않고 학습된 위치를 "암기"한 것처럼 보임
2. 종이컵이 비어 있으면 무조건 큐브가 존재하는 것으로 행동 — 탐색을 멈추지 않음
3. **컵 위치 고정 덕분에 파지 이후 구간은 안정적** — 병목이 파지 단계 하나로 좁혀짐
4. 지점 2·3·4에서 **재시도 행동** 관찰 — 이전 라운드에 없던 것

## 실패 분석

아래 ①~③은 저장된 데이터를 열어 직접 확인한 것이고, ④~⑥은 거기서 끌어낸 해석입니다. 확인한 것과 해석을 구분해 적습니다. → [데이터 확인 기록](../dataset-analysis.md)

### 확인 ①  지점당 3회로는 지점별 차이를 판단할 수 없습니다

성공한 지점(2·3·4)과 전멸한 지점(1·5·6)이 갈렸지만, **지점당 3회는 너무 적습니다.** 실력이 같아도 3번 중 한 번도 못 하는 지점이 우연히 생깁니다.

→ **"지점 1·5·6이 특별히 나쁘다"고 말할 근거가 없습니다.** 지점당 9회는 해봐야 판단할 수 있습니다.

### 확인 ②  7개 지점이 시연 데이터에서 서로 겹쳐 있습니다

학습에 쓴 42개 시연에서 **큐브를 집는 순간의 팔 자세**를 뽑아 지점별로 묶었습니다.

| 관절 | 7지점 전체가 퍼진 폭 | 같은 지점 안에서의 흔들림 |
| --- | ---: | ---: |
| 베이스 회전 | 12.8° | ±3.3° |
| 팔 뻗음 | 31.0° | ±11.0° |

**지점 사이 간격보다 같은 지점 안에서의 흔들림이 더 컸습니다.** 지점 3은 72.4±3.4°, 지점 4는 72.9±0.9°로 베이스 회전각이 사실상 같습니다. 옆 지점끼리 자세가 포개져 있다는 뜻입니다.

→ **운영자 가설의 재해석이 필요합니다.** 평가는 학습한 7지점에 정확히 배치했으므로, 정책이 위치를 "암기"했다면 오히려 성공했어야 합니다. 데이터가 가리키는 것은 **암기가 아니라 애초에 구분할 수 없는 데이터였다**는 것입니다.

### 확인 ③  학습 데이터에 다시 잡는 시연이 0개입니다

42개 시연 전부 그리퍼를 **정확히 한 번만** 닫았습니다. 엣지 케이스 8개(ep 42–49)는 닫은 적이 없습니다.

→ **평가에서 나온 재시도 행동은 시연을 따라 한 것이 아닙니다.**

### 추론 ④  겹친 지점 + 미리 정해둔 동작

②·③을 정책이 움직이는 방식과 연결한 해석입니다. **검증되지 않았습니다.**

```
화면 한 장을 본다
  ↓ 그 화면만으로는 7지점 중 어디인지 가려낼 만한 단서가 안 나온다   [②]
겹쳐 있는 지점들의 중간쯤 되는 궤적을 고른다
  ↓ 그 궤적으로 3.3초치 동작을 미리 정해두고 (n_action_steps=100)
  ↓ 중간에 어긋나도 다시 보지 않고 끝까지 실행한다
"큐브가 있는 걸 아는 듯한데 다른 곳을 짚음"
```

겹친 지점들의 중간 궤적을 골라 3.3초 동안 되돌릴 수 없다는 것이 요지입니다. **[실험 A/B](experiment-ab.md)가 방증입니다** — 화면을 더 자주 보고 다시 계산하게 바꿨더니 오히려 팔이 떨렸습니다. 매번 다른 판단이 나온다는 것은 **화면에서 뽑아내는 위치 단서가 애초에 불안정하다**는 뜻입니다.

### 추론 ⑤  재시도 행동의 정체

③으로 "시연 모방" 해석은 기각됐습니다. 남은 해석 둘은 사실상 같은 메커니즘으로 수렴합니다.

| 해석 | 평가 |
| --- | --- |
| 실패를 인지한 의도적 복구 | 학습 데이터에 복구 시연이 **0개**이므로 "학습된 복구 행동"일 수 없음 |
| **3.3초마다 다시 계산하다 생긴 부산물** | 3.3초가 지나면 화면을 새로 본다. 파지에 실패한 직후의 모습(큐브가 보이고 그리퍼는 열린 채 근처)은 **접근하던 중의 화면과 비슷하다.** 그래서 접근 동작을 다시 만들어낸다. **가장 단순하고 데이터와 어긋나지 않음** |

확정하려면 재시도가 시작된 시점이 3.3초의 배수와 맞아떨어지는지 실행 기록으로 확인해야 하는데, **장비 반납으로 검증하지 못했습니다.** 두 해석 모두 "복구 능력을 획득했다"는 주장을 지지하지 않는다는 점은 같습니다.

### 추론 ⑥  큐브가 없어도 멈추지 않는 문제

"큐브 없음" 정지 데이터가 4개로 전체의 **8%** 뿐이었습니다. 2차(40%)·3차(20%)에서는 정지 동작이 정상 학습됐던 것에 비하면 회귀입니다.

다만 **근본 원인은 ②와 같을 수 있습니다** — 큐브가 어디 있는지 제대로 못 짚는다면 있는지 없는지도 구분하지 못합니다. 정지 데이터만 늘려서는 해결되지 않을 가능성이 있습니다.

## 성과와 한계 — 프로젝트 종료

**성과 — 병목이 하나로 좁혀졌습니다.**

| | 3차 | 5차 |
| --- | --- | --- |
| 성공 | 4/20 (20%) | **7/21 (33%)** |
| 파지 후 실패 | 5 | **0** |

컵 위치 고정으로 파지 이후 구간(이송 → 투입 → 복귀)이 안정화됐고, 실패가 **전부 파지 단계**로 모였습니다. 3차에서 파지 성공 9건 중 5건이 컵 단계에서 깨졌던 것과 대비됩니다.

**한계 — 33%는 실용 수준이 아닙니다.** 남은 병목은 시각적 위치 판별이며, 원인은 ②로 좁혀졌습니다. 다음 단계는 [Future Work](../findings.md)에 정리했습니다.
