## 설계

1~4차의 결론을 전부 반영해 **데이터를 새로 수집하고 처음부터 학습**했습니다. 이전 라운드의 데이터·가중치를 이어받지 않았습니다.

### 데이터 구성

- 데이터셋: `k-chan-l/pick_and_place5` — **50 에피소드 / 24,407 프레임**

| 종류 | 에피소드 | 구성 |
| --- | --- | --- |
| 정상 시연 | 42 | 7지점 × 6회 (각도 0°/45° 3:3) |
| 엣지 케이스 | 8 | 큐브가 이미 컵 안 4 + 큐브 없음 4 |

- DAgger 교정 17ep는 **제외**했습니다 (4b 결론 2).

### 촬영 조건

전체 조건은 [protocol.md](../protocol.md)의 "5차 통제 실험 조건"에 있습니다. 핵심만:

| 항목 | 값 | 근거 |
| --- | --- | --- |
| 컵 | **물리적으로 고정** | 3차에서 컵 전도 3회로 시행 조건이 흔들림 |
| 큐브 지점 | 7지점, 탈착식 종이 템플릿으로 배치 후 **템플릿 제거** | 표시가 프레임에 남으면 그것을 단서로 학습 (1차 causal confusion) |
| 큐브 각도 | 0° / 45° | 3차 가설 1 — 각도 다양성 부족 |
| 위치 오차 | 시연 시 ±1~2cm 랜덤 / 평가 시 정확히 | 학습엔 다양성, 평가엔 재현성 |
| 카메라 | MJPEG, **자동 노출·화이트밸런스 off** | 프레임 간 밝기·색 흔들림 제거 |
| 시연 | **정렬 구간 1~2초 천천히**, 파지 후 멈춤 없이 곧장 컵 | 4b 결론 3 — 중앙 정렬 미학습 |
| 편집 | 멈칫한 에피소드는 즉시 삭제 | 4차 회귀 원인 차단 |

### 학습

- 정책: `k-chan-l/pick_and_place5_act`
- **from scratch** / 100,000 steps / batch_size 16 / seed 1000 / `image_transforms.enable=true`

## 결과

**21회 중 7회 성공 (33%)** — `n_action_steps=100` 기준. **전 라운드 최고 성적입니다.**

| 항목 | 값 |
| --- | --- |
| 총 시행 | 21 (7지점 × 3회) |
| 성공 | **7 (33%)** |
| 근접 오차 | 미분류 |
| 파지 실패 | 14 |
| 파지 후 실패 | **0** |
| 무반응 | 0 |

> 실패 14건은 전부 파지 단계입니다. 운영자 관찰상 "다른 위치를 짚음"(접근 오류)과 "근처에서 파지 실패"가 섞여 있으나 시행 단위로 분리 기록되지 않아 **근접 오차와 파지 실패를 나누지 않았습니다.**

### 지점별 결과

| 지점 | 결과 | 관찰된 행동 |
| --- | --- | --- |
| 1 | 0/3 | 큐브 존재는 인지하는 듯하나 다른 위치를 탐색 |
| 2 | **2/3** | 위치를 어렴풋이 찾음. 주변을 여러 번 헛짚다가 겨우 파지 |
| 3 | **2/3** | 위치를 알고 접근. 주변을 짚다가 파지 성공 |
| 4 | **2/3** | 파지 실패 시 다른 위치로 이동해 재시도 후 파지 |
| 5 | 0/3 | 위치를 모르고 다른 곳을 짚음 |
| 6 | 0/3 | 위치를 모르고 다른 곳을 짚음 |
| 7 | 1/3 | 주변을 짚다 실패하면 다른 곳을 잡으려 함 |

### 운영자 관찰

1. 정책이 큐브를 시각적으로 탐지하지 않고 학습된 위치를 "암기"한 것처럼 보임
2. 종이컵이 비어 있으면 무조건 큐브가 존재하는 것으로 행동 — 탐색을 멈추지 않음
3. **컵 위치 고정 덕분에 파지 이후 구간은 안정적** — 병목이 파지 단계 하나로 좁혀짐
4. 지점 2·3·4에서 **재시도 행동** 관찰 — 이전 라운드에 없던 것

## 실패 분석

세 가지는 [데이터셋 사후 분석](../dataset-analysis.md)에서 **데이터로 검증**했습니다. 검증된 사실과 추론을 아래에 구분해 적습니다.

### 검증됨 ①  지점별 성공률 편차는 통계적으로 유의하지 않습니다

전 지점이 동일하게 33%라고 가정해도 0/3인 지점이 평균 2.1개 나옵니다 (관측 3개). 관측된 분산 이상이 우연히 나올 확률은 **16.9%**입니다.

→ **"지점 1·5·6이 특별히 나쁘다"는 이 데이터로 주장할 수 없습니다.** 지점당 9회 이상 필요합니다.

### 검증됨 ②  7개 지점이 시연 데이터에서 분리되지 않습니다

파지 순간의 관절값을 지점별로 묶은 결과입니다.

| 관절 | 7지점 전체 폭 | 지점 간 표준편차 | 지점 내 산포 | 분리비 |
| --- | ---: | ---: | ---: | ---: |
| j1 (베이스 회전) | 12.8° | 4.5° | 3.3° | **1.36** |
| j3 (팔 뻗음) | 31.0° | 11.0° | 11.0° | **1.00** |

분리비가 1 근처면 인접 지점의 시연 분포가 서로 겹칩니다. 실제로 지점 3(72.4±3.4°)과 지점 4(72.9±0.9°)는 베이스 회전각이 사실상 같습니다.

→ **운영자 가설의 재해석이 필요합니다.** 평가는 학습한 7지점에 정확히 배치했으므로, 정책이 위치를 "암기"했다면 오히려 성공했어야 합니다. 데이터가 가리키는 것은 **암기가 아니라 애초에 구분 불가**입니다.

### 검증됨 ③  학습 데이터에 다중 시도 시연이 0개입니다

42개 시연 전부 그리퍼 닫힘이 **정확히 1회**입니다. 엣지 케이스 8개(ep 42–49)는 닫힘이 없습니다.

→ **재시도 행동은 시연을 모방한 것이 아닙니다.**

### 추론 ④  겹친 지점 + open-loop commitment

②·③과 ACT 구조를 연결한 해석입니다. **검증되지 않았습니다.**

```
관측 1프레임 (n_obs_steps=1)
  ↓ 시각 인코더가 7지점을 구분할 만큼의 위치 신호를 내지 못함   [②]
CVAE 잠재변수 = 0 (추론 시) → 조건부 평균 액션 시퀀스
  ↓ 100스텝 청크를 생성해 n_action_steps=100으로 전부 실행
  ↓ 30fps에서 3.33초 open-loop, 중간 보정 없음
"큐브가 있는 걸 아는 듯한데 다른 곳을 짚음"
```

겹친 지점들의 평균 궤적으로 커밋한 뒤 3.33초간 되돌릴 수 없다는 것이 요지입니다. **[실험 A/B](experiment-ab.md)가 방증입니다** — 재계획을 자주 시키자 오히려 진동했고, 이는 프레임 단위 시각 신호가 신뢰할 수 없다는 뜻입니다.

### 추론 ⑤  재시도 행동의 정체

③으로 "시연 모방" 해석은 기각됐습니다. 남은 해석 둘은 사실상 같은 메커니즘으로 수렴합니다.

| 해석 | 평가 |
| --- | --- |
| 실패를 인지한 의도적 복구 | 학습 데이터에 복구 시연이 **0개**이므로 "학습된 복구 행동"일 수 없음 |
| **청크 경계 재계획 부산물** | 3.33초마다 새로 관측 → 파지 실패 직후 상태(큐브가 보이고 그리퍼가 열린 채 근처)가 **접근 단계 학습 분포와 유사** → 접근 궤적을 다시 생성. **가장 단순하고 데이터와 모순 없음** |

확정하려면 재시도 시점이 청크 경계(3.33초의 배수)에 정렬되는지 롤아웃 로그로 확인해야 하나 **장비 반납으로 검증하지 못했습니다.** 두 해석 모두 "복구 능력을 획득했다"는 주장을 지지하지 않는다는 점은 같습니다.

### 추론 ⑥  큐브가 없어도 멈추지 않는 문제

"큐브 없음" 정지 데이터가 4개로 전체의 **8%** 뿐이었습니다. 2차(40%)·3차(20%)에서는 정지 동작이 정상 학습됐던 것에 비하면 회귀입니다.

다만 **근본 원인은 ②와 같을 수 있습니다** — 큐브 위치를 신뢰성 있게 잡지 못하면 유무도 구분하지 못합니다. 정지 데이터만 늘려서는 해결되지 않을 가능성이 있습니다.

## 성과와 한계 — 프로젝트 종료

**성과 — 병목이 하나로 좁혀졌습니다.**

| | 3차 | 5차 |
| --- | --- | --- |
| 성공 | 4/20 (20%) | **7/21 (33%)** |
| 파지 후 실패 | 5 | **0** |

컵 위치 고정으로 파지 이후 구간(이송 → 투입 → 복귀)이 안정화됐고, 실패가 **전부 파지 단계**로 모였습니다. 3차에서 파지 성공 9건 중 5건이 컵 단계에서 깨졌던 것과 대비됩니다.

**한계 — 33%는 실용 수준이 아닙니다.** 남은 병목은 시각적 위치 판별이며, 원인은 ②로 좁혀졌습니다. 다음 단계는 [Future Work](../findings.md)에 정리했습니다.
