- 4차와 **데이터·초기 가중치·steps 전부 동일**하고 `image_transforms.enable=true` 만 다릅니다.
  - `pick_and_place4`(67ep) / 3차 체크포인트에서 40,000 steps / batch_size 16
- 목적: 4차 회귀가 **증강 제거** 탓인지 **DAgger 노이즈** 탓인지 분리.
- 평가는 `n_action_steps=100`으로 10회 (4차의 0/10과 같은 설정).

### 결과

**10회 중 0회 성공 (0%).** 성공률은 4차와 같지만 **거동이 완전히 다릅니다.**

| 항목 | 값 |
| --- | --- |
| 총 시행 | 10 |
| 성공 | 0 |
| 파지 실패 | 8 |
| 파지 후 실패 | 2 |
| 근접 오차 | 0 |
| 무반응 | 0 |
| **큐브 근접** | **10 / 10** |

시행별 기록 (시연자 직접 관찰):

| 회차 | 분류 | 관찰 |
| --- | --- | --- |

| 3 | 파지 실패 | 파지 실패 후 재파지도 실패 |
| 4 | 파지 실패 | |
| 5 | 파지 실패 | |
| 6 | 파지 실패 | |
| 7 | 파지 실패 | |
| 8 | 파지 실패 | |

| 10 | 파지 후 실패 | 파지 성공, 컵 위치를 찾지 못함 |

요약: 정밀 파지 실패 7 / 파지 중 놓침 1 / 파지 성공 2 (둘 다 컵 단계에서 실패).

**핵심 관찰** — 손목캠에 큐브가 보이지만 **중앙 정렬이 되지 않은 상태에서 파지 모션을 실행**합니다. 큐브 근처까지는 정확히 가는데, 마지막 정렬 없이 그 자리에서 그리퍼를 닫습니다.

### 라운드 비교

| | 3차 | 4차 | 4b |
| --- | --- | --- | --- |
| 데이터 | 3차 50ep | 3차 + DAgger 17ep | 3차 + DAgger 17ep |
| 증강 | on | **off** | **on** |
| 초기화 | from scratch 100k | 3차에서 40k | 3차에서 40k |
| 성공 | **4/20 (20%)** | 0/10 | 0/10 |
| 큐브 근접 | 19/20 (95%) | 허공 잡음 3/10 | **10/10 (100%)** |
| 파지 성공 | **9/20 (45%)** | 2/10 (20%) | 2/10 (20%) |
| 컵 단계 도달 | 9 | 1 | 2 |

### 결론

**1. 4차 허공 잡음의 주범은 증강 제거입니다.** 데이터·초기 가중치·steps가 전부 같은데 증강만 켜자 큐브 근접이 3/10 수준에서 **10/10으로 복구**됐습니다. 증강이 시각적 주의를 받치고 있었고, 40k steps 동안 증강 없이 좁은 데이터에 학습하자 그것이 무너진 것입니다.
→ **5차 증강 on 확정.**

**2. DAgger 17ep는 정밀 파지에 기여가 없거나 유해합니다.** 4b는 근접을 되찾았는데도 파지 성공률이 **3차 45% → 4b 20%** 로 오히려 낮습니다. 증강이라는 교란 변수를 제거하고 보면 교정 데이터가 정밀도를 끌어올리지 못했습니다.
→ **5차에서 17ep 제외 확정.**

> 4차 시점의 진단(교정 데이터가 좁은 관절 영역에 뭉쳐 평균화)은 **허공 잡음의 원인으로는 반증**됐습니다. 그 부분은 증강 제거가 설명합니다. 다만 교정 데이터가 정밀 파지를 개선하지 못한 것은 그대로 관측됐으므로, 진단의 방향 자체가 틀린 것은 아닙니다.

**3. 1~4차를 관통하는 근본 문제가 드러났습니다.** 정책은 **"큐브가 보이면 잡는다"는 배웠지만 "큐브를 중앙에 정렬한 뒤 잡는다"는 배우지 못했습니다.**

- 3차 시연자 관찰: "큐브를 가운데 두고 잡지 않고 조금 보이면 잡는다"
- 4b 시연자 관찰: "손목캠에 큐브가 보이지만 중앙에 있지 않은데도 파지 모션 실행"
- A/B 실험: 폐루프로 바꾸자 오히려 나빠짐 — 관측을 정렬 신호로 쓰지 못한다는 증거

세 라운드의 관찰이 같은 결론을 가리킵니다. 시연 데이터에 **정렬 과정이 관측 가능한 형태로 남아 있지 않은 것**이 원인으로 보입니다. 사람은 정렬을 순간적으로 끝내므로, 30fps에서 정렬 구간이 몇 프레임에 불과해 학습 신호가 되지 못합니다.
→ **5차 시연 프로토콜에 정렬 구간 명시적 기록 추가** (→ [protocol.md](../protocol.md)).
