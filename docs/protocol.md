# 평가 프로토콜

라운드 간 성공률을 비교하려면 평가 조건이 같아야 합니다. 이 문서는 평가 방법과 실패 유형 정의, 그리고 5차부터 적용하는 통제 조건을 정의합니다.

## 적용 범위

| 라운드 | 평가 방식 |
| --- | --- |
| 1~2차 | 프로토콜 이전. 2차는 10회 축약 평가, 지점 고정 없음 |
| 3~4차 | 4~5지점 × 4회 = 20회 (탐색 단계 프로토콜, 아래 결함 있음) |
| **5차~** | **5차 통제 실험 조건** (아래) |

## 태스크

`Pick up the blue cube and place it in the paper cup.`

---

## 성공 기준

다음을 **모두** 만족해야 성공입니다.

1. 큐브를 파지한다.
2. 큐브를 **종이컵 안에 넣는다** (컵 밖으로 튕겨 나오거나 **컵이 넘어지면 실패**).
3. 팔이 **원위치(홈 포지션)로 복귀**한다.
4. 위 전부를 **30초 안에** 완료한다.

> 4번 조건은 시행마다 반드시 확인하고 기록합니다. 3차 평가에서 복귀 여부가 누락되어 성공 4회의 판정 근거가 불완전하게 남았습니다.

## 실패 유형

실패한 시행은 아래 4종 중 하나로 분류합니다. 이 분포가 다음 라운드에서 어떤 데이터를 보강할지를 결정합니다.

| 유형 | 정의 | 시사점 |
| --- | --- | --- |
| **근접 오차** | 큐브 쪽으로 접근하지만 위치가 어긋나 파지 시도 자체가 큐브에 닿지 않음 | 위치 조건부 접근 능력 부족 — 위치 다양성 / 관측 정합성 문제 |
| **파지 실패** | 큐브에 도달했으나 그립에 실패하거나 잡자마자 놓침 | 정밀 정렬·그립 타이밍 문제 — 손목캠 단서 부족, 각도 일반화 실패 |
| **파지 후 실패** | 파지에는 성공했으나 이송/투입/복귀 단계에서 실패 (컵 밖에 떨어뜨림, 컵을 넘어뜨림, 이송 중 놓침, 복귀 안 함, 시간 초과) | 후반 궤적 학습 부족 또는 compounding error |
| **무반응** | 큐브가 있는데도 팔이 거의 움직이지 않음 | 정지 데이터 과다 / 정지 상태로의 mode collapse |

> 정지 데이터가 의도대로 학습됐는지는 별도로 확인합니다 — **큐브가 없는 상태**에서 팔이 움직이지 않으면 정상이며, 이 경우의 무반응은 실패로 세지 않습니다.

## 평가 시 반드시 함께 기록할 것

성공률 숫자만으로는 라운드 비교가 불가능합니다. 아래를 결과와 같이 남깁니다.

| 항목 | 이유 |
| --- | --- |
| **`n_action_steps`** (및 `temporal_ensemble_coeff`) | 같은 가중치라도 이 값에 따라 성공률이 달라집니다. A/B 실험에서 100 > TE > 20으로 확인됨 |
| 정책 체크포인트 (repo_id 또는 로컬 경로 + steps) | 어느 가중치인지 |
| 카메라 설정 (`fourcc`, 노출·화이트밸런스 고정값) | 관측 분포가 학습 데이터와 맞는지 |
| 큐브 지점 배치 버전 | 지점이 바뀌면 비교 불가 |

**서로 다른 추론 설정에서 나온 성공률을 나란히 비교하지 않습니다.** 어떤 라운드를 이전 라운드와 비교하려면 그 라운드가 평가된 것과 **같은 설정**에서 측정해야 합니다.

## 기록 양식

라운드마다 [experiments.md](experiments.md)에 아래 표를 채웁니다.

| 항목 | 값 |
| --- | --- |
| 총 시행 | 21 |
| 성공 | n (n/21 = xx%) |
| 근접 오차 | n |
| 파지 실패 | n |
| 파지 후 실패 | n |
| 무반응 | n |

시행별로도 남깁니다: `회차 | 지점 | 각도 | 결과 | 분류 | 소요시간 | 홈 복귀 | 비고`

롤아웃 영상은 [media/](../media/)에 `round<N>_<지점>_<시행번호>.mp4` 형식으로 둡니다.

## 탐색 단계 프로토콜 (3~4차) — 알려진 결함

3~4차 평가에 실제로 쓰인 조건이며, 5차에서 아래 결함을 모두 고칩니다.

| 항목 | 값 |
| --- | --- |
| 큐브 시작 위치 | 작업공간 내 4~5개 고정 지점 |
| 지점당 시행 | 4회 (총 20회) |
| 시행당 제한 시간 | 30초 |

**발견된 결함**

1. **도달 불가 지점** — 3차 13회차에서 큐브가 팔이 닿지 않는 위치에 배치됐습니다. 정책 성능과 무관한 시행이 매 라운드 하나씩 낍니다. 모든 지점은 사전에 텔레오퍼레이션으로 도달 가능성을 확인해야 합니다.
2. **컵 리셋 기준 없음** — 3차에서 컵이 3회(3·9·12회차) 넘어졌습니다. 컵이 넘어진 뒤 다음 시행의 컵 위치가 달라져 조건이 흔들렸습니다.
3. **큐브 각도 미통제** — 각도가 기록되지 않아, 3차의 최대 병목(각도별 파지 성공률 차이)을 사후에 정량화할 수 없습니다.
4. **홈 복귀 미기록** — 성공 기준 4개 중 하나가 확인되지 않았습니다.

## 5차 통제 실험 조건

5차부터는 **한 번에 한 변수만** 바꿉니다. 아래 조건은 라운드가 바뀌어도 고정합니다.

### 학습

| 항목 | 값 |
| --- | --- |
| 데이터셋 | `k-chan-l/pick_and_place5` (신규) |
| 초기화 | **from scratch** — 이전 체크포인트를 이어받지 않음 |
| steps | 100,000 |
| batch_size | 16 |
| seed | 고정 (1000) |
| `image_transforms` | **on** — 단, 4b 결과에 따라 재검토 |

이전 데이터셋·가중치를 섞지 않습니다. 4차에서 fine-tune이 좁은 교정 데이터에 끌려간 것이 회귀 원인이었습니다.

### 카메라 (촬영·평가 공통)

- `fourcc: MJPG`, 640×480 / 30fps — 수집과 평가 **양쪽 모두**에 적용.
- **자동 화이트밸런스·자동 노출 off, 고정값 사용.** `v4l2-ctl`로 설정하며 실제 값은 [setup.md](../setup.md)에 기록합니다.
- 이 설정은 **재연결하면 초기화됩니다.** 촬영을 여러 세션에 나눠 진행하면 세션마다 노출이 달라져 새 변수가 생깁니다. 스크립트로 만들어 매 세션 시작 시 실행합니다.

### 배치

| 항목 | 값 |
| --- | --- |
| 컵 | **한 위치 고정.** 컵 바닥에 가려지는 테이프로 바닥에 표시 |
| 큐브 지점 | **7지점** |
| 지점 표시 | **탈착식 종이 템플릿(구멍)** 으로 배치한 뒤 **템플릿 제거** |
| 큐브 각도 | **0° / 45°** |
| 위치 오차 | 시연 시 지점 기준 **1~2cm 랜덤 오프셋** / 평가 시 **정확히** 지점에 배치 |

- 템플릿을 반드시 제거하고 촬영합니다. 지점 표시가 프레임에 남으면 정책이 큐브 대신 그 표시를 단서로 학습할 수 있습니다 (1차의 causal confusion과 같은 실패).
- 시연에만 랜덤 오프셋을 주는 이유: 학습 데이터에는 위치 다양성이 필요하지만, 평가는 라운드 간 비교를 위해 재현 가능해야 합니다.
- 모든 지점은 사전에 **도달 가능성을 확인**합니다.

### 시연 프로토콜

1. 전체뷰(`cam_top`)로 큐브 확인
2. **파지 접근은 손목캠(`cam_wrist`)을 보며 정렬**
3. 파지
4. **파지 후 멈춤 없이 곧장 컵으로** → 놓기 → 원위치 복귀

- **멈칫한 에피소드는 즉시 삭제합니다.** 망설임·재시도·더듬기가 들어간 구간은 같은 관측에 서로 다른 액션을 붙여 정책을 평균으로 끌어내립니다 (4차 회귀의 직접 원인).
- 3차의 6단계 프로토콜에서 "전체뷰로 컵 확인" 단계를 뺐습니다. 그 확인 동작이 파지 후 정지 구간을 만들었고, 컵 단계 실패와 맞물릴 가능성이 있습니다.

### 데이터 구성

| 종류 | 에피소드 | 구성 |
| --- | --- | --- |
| 정상 시연 | **42** | 7지점 × 6회 |
| 정지(no-op) | **8** | 큐브가 이미 컵 안 4 + 큐브 없음 4 |
| 합계 | **50** | |

- 정상 시연은 지점당 6회이며 각도 0°/45°를 **지점마다 3회씩** 나눠 찍습니다 (지점당 0° 3회 + 45° 3회).
- 정지 데이터는 2종입니다. 2·3차의 3종(컵만 있고 큐브 없음 / 큐브 없음 / 큐브가 이미 컵 안)에서 앞의 둘이 사실상 같은 상황이라 하나로 합쳤습니다.
- 정지 비율은 3차 20% → **16%**. 정지 행동은 2차에서 이미 학습이 확인됐으므로 성공 시연 쪽에 표본을 더 씁니다.

### 평가

| 항목 | 값 |
| --- | --- |
| 구성 | **7지점 × 3회 = 21회** |
| 제한 시간 | 30초 |
| 기준선 추론 설정 | **`n_action_steps=100`** |
| 추가 시험 | 기준선 확정 후 `n_action_steps=20`, temporal ensembling 재시험 |

지점당 3회는 각도 2종으로 딱 나뉘지 않습니다. 라운드 간 재현을 위해 배분을 고정합니다 — **시행 1은 0°, 시행 2는 45°, 시행 3은 지점 번호가 홀수면 0° / 짝수면 45°.** 7지점 기준 0° 11회 : 45° 10회가 되며, 이 배분은 라운드가 바뀌어도 동일하게 씁니다.

기준선을 100으로 두는 이유는 A/B 실험에서 100이 가장 나았기 때문이며, 3·4차 숫자와 비교 가능한 유일한 설정이기 때문입니다. 20·TE 재시험은 **5차 기준선이 확정된 뒤**에 합니다 — 데이터가 바뀌면 폐루프 설정의 유불리도 달라질 수 있습니다.

### DAgger

**5차 기준선이 확정된 뒤에** 진행합니다. 조건:

- 정책의 추론 설정을 확정한 뒤 수집합니다. 설정이 바뀌면 정책의 실패 상태 분포도 바뀌므로, 이전 설정에서 모은 교정 데이터는 맞지 않습니다.
- **한 번에 깔끔하게 복구되는 시연만** 녹화합니다. 더듬거나 여러 번 시도한 구간은 버립니다.
- `--strategy.record_autonomous=false` (corrections-only) 를 유지합니다.
