# 평가 프로토콜

라운드 간 성공률을 비교하려면 평가 조건이 같아야 합니다. 3차부터 아래 프로토콜을 표준으로 사용합니다.

## 태스크

`Pick up the blue cube and place it in the paper cup.`

## 시행 구성

| 항목 | 값 |
| --- | --- |
| 큐브 시작 위치 | 작업공간 내 **4~5개 고정 지점** |
| 지점당 시행 | **4회** |
| 총 시행 | **20회** (5지점 × 4회 기준) |
| 시행당 제한 시간 | **30초** |
| 컵 위치 | 전 시행 고정 |
| 팔 시작 자세 | 전 시행 동일한 홈 포지션 |

- 큐브 위치 지점은 학습 데이터의 위치 분포를 커버하도록 배치하고, 라운드가 바뀌어도 **동일한 지점**을 씁니다 (위치를 바꾸면 라운드 간 성공률 비교가 무의미해짐).
- 각 시행 전에 큐브·컵을 지정 위치로 리셋하고 팔을 홈 포지션으로 되돌립니다.
- 시행 중 사람이 개입하지 않습니다. 30초가 지나면 실패로 기록합니다.

## 성공 기준

다음을 **모두** 만족해야 성공입니다.

1. 큐브를 파지한다.
2. 큐브를 **종이컵 안에 넣는다** (컵 밖으로 튕겨 나오면 실패).
3. 팔이 **원위치(홈 포지션)로 복귀**한다.
4. 위 전부를 **30초 안에** 완료한다.

## 실패 유형

실패한 시행은 아래 4종 중 하나로 분류합니다. 이 분포가 다음 라운드에서 어떤 데이터를 보강할지를 결정합니다.

| 유형 | 정의 | 시사점 |
| --- | --- | --- |
| **근접 오차** | 큐브 쪽으로 접근하지만 위치가 어긋나 파지 시도 자체가 큐브에 닿지 않음 | 위치 조건부 접근 능력 부족 — 위치 다양성 / 관측 정합성 문제 |
| **파지 실패** | 큐브에 도달했으나 그립에 실패하거나 잡자마자 놓침 | 정밀 정렬·그립 타이밍 문제 — 손목캠 단서 부족, 시간 정렬 손상 의심 |
| **파지 후 실패** | 파지에는 성공했으나 이송/투입/복귀 단계에서 실패 (컵 밖에 떨어뜨림, 이송 중 놓침, 복귀 안 함, 시간 초과) | 후반 궤적 학습 부족 또는 compounding error |
| **무반응** | 큐브가 있는데도 팔이 거의 움직이지 않음 | 정지 데이터 과다 / 정지 상태로의 mode collapse |

> 참고: 정지 데이터가 의도대로 학습됐는지는 별도로 확인합니다 — **큐브가 없는 상태**에서 팔이 움직이지 않으면 정상이며, 이 경우의 무반응은 실패로 세지 않습니다.

## 이전 라운드와의 차이

- **1차·2차는 이 프로토콜 이전**의 평가입니다. 2차는 20회가 아니라 **10회 축약 평가**(성공 2회)였고 지점 배치도 고정되어 있지 않았으므로, 3차 이후 수치와 직접 비교할 때는 이 점을 감안해야 합니다.
